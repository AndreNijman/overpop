# Balance report

Generated by `node tools/playthroughs.mjs`. Every number here comes from a real
headless playthrough of the shipped bundle, not from an estimate.

## Method

Two builds are played on one map per difficulty tier, across the difficulty and
mode matrix:

- **Reference build** — spend everything, spread coverage along the whole track,
  upgrade what is already covering it before widening, keep a small cash reserve.
  Not a clever build; the build a competent player converges on.
- **Inadequate build** — one cheap tower, never upgraded.

The reference build must hold. The inadequate build must leak. Asserting only the
first would be satisfied by a game where nothing can ever leak.
